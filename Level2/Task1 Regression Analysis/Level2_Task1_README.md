# Task 1 - Regression Analysis | Level 2

## Overview

Performing simple linear regression to predict one variable based on another. The task covers the full workflow from splitting the data to evaluating the model's performance.

## Objectives

- Split the dataset into training and testing sets
- Fit a linear regression model using scikit-learn
- Interpret model coefficients
- Evaluate performance using R-squared and Mean Squared Error

## Tools & Libraries

- Python
- pandas
- scikit-learn

## Project Structure

```
├── notebook.ipynb
├── dataset.csv
└── README.md
```

## Notes

Model evaluation is done on the test set only. Coefficients are interpreted in context of the dataset to understand the direction and magnitude of each feature's effect on the target variable.
