# Task 2 - Basic Data Visualization | Level 1

## Overview

Creating basic plots and charts to explore the distribution and relationships within the dataset. The focus is on producing clear, readable visuals that can be used in reports or presentations.

## Objectives

- Create bar plots, line charts, and scatter plots
- Customize labels, titles, and legends for each plot
- Export all plots as image files

## Tools & Libraries

- Python
- matplotlib
- seaborn

## Project Structure

```
├── notebook.ipynb
├── dataset.csv
├── outputs/
│   └── (exported plot images)
└── README.md
```

## Notes

All plots are exported to the `outputs/` folder as `.png` files using `plt.savefig()`. Seaborn is used for statistical plots while matplotlib handles general-purpose charting.
