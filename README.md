# Codveda Data Analysis Internship

A collection of data analysis tasks completed during my internship at Codveda,
covering data cleaning, visualization, regression, time series analysis,
predictive modeling, and dashboard building.
All tasks were implemented using Python on Google Colab.

---

## Tasks Overview

| Level | Task | Description | Dataset | Tools |
|-------|------|-------------|---------|-------|
| Level 1 | Data Cleaning & Preprocessing | Handle missing values, duplicates, and inconsistent formats | Stock Price Dataset | pandas |
| Level 1 | Basic Data Visualization | Create and export basic plots and charts | House Prediction Dataset | matplotlib, seaborn |
| Level 2 | Regression Analysis | Build and evaluate a linear regression model | Stock Price Dataset | scikit-learn, pandas |
| Level 2 | Time Series Analysis | Detect trends and seasonality in time-series data | Stock Price Dataset | statsmodels, pandas |
| Level 3 | Predictive Modeling / Classification | Train and evaluate classification models | Churn Dataset (bigml-80) | scikit-learn, pandas |
| Level 3 | Building Dashboards | Create interactive dashboards | Churn Dataset | Power BI |
