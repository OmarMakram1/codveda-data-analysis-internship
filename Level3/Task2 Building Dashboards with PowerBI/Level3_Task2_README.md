# Task 2 - Building Dashboards | Level 3

## Overview

Creating an interactive dashboard using Power BI to present insights from a dataset. The dashboard is designed for non-technical stakeholders and allows dynamic exploration through filters and slicers.

## Objectives

- Import and clean the dataset inside Power BI
- Build interactive visualizations including bar charts, line graphs, and KPI cards
- Add filters and slicers for dynamic exploration
- Publish and share the dashboard

## Tools

- Power BI Desktop

## Notes

The dashboard file (`Customer Churn Dashboard.pbix`) is included in the `Dashboard/` folder. Open it with Power BI Desktop to view or edit. Screenshots of the final dashboard are available in the `Images/` folder.
